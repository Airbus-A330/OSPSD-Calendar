# Shared Calendar HTTP Contract

## Status

This document will describe the HTTP representation of the shared Calendar
contract agreed to by Teams 2, 5, and 7.

The authoritative design decisions currently live in the shared Calendar
decision memo.

## Common Operations

- `POST /events`
- `GET /events/{event_id}`
- `PUT /events/{event_id}`
- `DELETE /events/{event_id}`

## Common Event Fields

- `id`
- `title`
- `start`
- `end`
